# Архив чатов

Приложение для просмотра переписки, импортированной из Telegram. Есть отдельные приложения для
**Windows**, **Android** и **iPhone**, а также веб-версия. Данные хранятся только на устройстве,
на сервер ничего не отправляется.

## Скачать

Готовые файлы собираются автоматически при каждом изменении в `main` и лежат в разделе
**Releases → latest** этого репозитория:

| Устройство | Файл | Как установить |
|---|---|---|
| Windows | `ChatArchive-windows-setup.exe` | Запустить установщик. Если SmartScreen предупредит: «Подробнее» → «Выполнить в любом случае». |
| Windows | `ChatArchive-windows-portable.exe` | Работает без установки. |
| Android | `ChatArchive-android.apk` | Скачать на телефон, открыть, разрешить «Установку из неизвестных источников». Новые версии ставятся поверх старой, чаты сохраняются. |
| iPhone | `ChatArchive-ios-unsigned.ipa` | Apple не разрешает ставить приложения мимо App Store без подписи. Подписать и установить можно бесплатно через [Sideloadly](https://sideloadly.io) или [AltStore](https://altstore.io) со своим Apple ID (с бесплатным аккаунтом подпись нужно обновлять раз в 7 дней). Без этого ограничения нужен Apple Developer Program (99 $ в год) — тогда можно распространять через TestFlight. |

## Как получить экспорт

Telegram Desktop → Настройки → Продвинутые настройки → **Экспорт данных** (или в чате ⋮ → **Экспорт истории чата**).
Формат: **«Машиночитаемый JSON»**. Отметьте фото, видео, голосовые и файлы, если они нужны.

В приложение можно загрузить:
- папку экспорта (кнопка «+» → «Выбрать папку», или перетащить папку в окно);
- ZIP-архив с папкой (удобно на телефоне);
- только `result.json` (без медиа).

Поддерживается экспорт одного чата и полный экспорт аккаунта (все чаты сразу).

## Повторный импорт

Чат узнаётся по его Telegram-ID. Если он уже есть в архиве, для него можно выбрать:
- **Дополнить**: новые сообщения добавляются, имеющиеся обновляются по ID сообщения. Дублей нет,
  старые сообщения, которых нет в новом экспорте, сохраняются;
- **Заменить**: старая версия удаляется целиком;
- **Создать новый чат**: отдельная копия;
- **Пропустить**.

## Медиа

- Анимированные стикеры (`.tgs`) проигрываются через Lottie, видеостикеры (`.webm`) — как видео
  (где формат не поддерживается, показывается превью).
- Голосовые (OGG/Opus) играют везде: если устройство не умеет OGG (iPhone), файл декодируется
  внутри приложения (WebAssembly).
- Кружки (видеосообщения) воспроизводятся по нажатию со звуком, с индикатором прогресса.
- ZIP не загружается в память целиком: читается оглавление архива, а файлы распаковываются по одному,
  поэтому большие архивы открываются и на телефоне.
- Файлы из сообщений в Android/iPhone сохраняются через системное меню «Поделиться».

## Устройство проекта

- `src/` — само приложение (React + TypeScript, хранение в IndexedDB).
- `electron/` — оболочка для Windows.
- `android/`, `ios/` — нативные проекты (Capacitor).
- `.github/workflows/build.yml` — сборка `.apk`, `.exe`, `.ipa` и публикация в Releases.
- `.github/workflows/pages.yml` — веб-версия на GitHub Pages (работает только для публичного репозитория).

```bash
npm install
npm run dev        # веб-версия локально
npm test           # тесты
npm run electron   # запустить версию для Windows/ПК
npm run dist:win   # собрать установщик Windows (на Windows)
npm run cap:sync   # обновить android/ и ios/ после изменений в src/
```

Android подписывается ключом `android/app/release.keystore` (одинаковым для всех сборок, чтобы обновления
ставились поверх). Для публикации в Google Play замените его своим через переменные `ANDROID_KEYSTORE_*`.
