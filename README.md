# Архив чатов

Приложение для просмотра переписки, импортированной из Telegram. Работает в браузере и устанавливается
как приложение (PWA) на Windows, Android и iPhone. Данные хранятся только на устройстве (IndexedDB),
на сервер ничего не отправляется.

## Как получить экспорт

Telegram Desktop → Настройки → Продвинутые настройки → **Экспорт данных** (или в чате ⋮ → **Экспорт истории чата**).
Формат: **«Машиночитаемый JSON»**. Отметьте фото, видео, голосовые и файлы, если они нужны.

В приложение можно загрузить:
- папку экспорта (кнопка «+» → «Выбрать папку», или перетащить папку в окно);
- ZIP-архив с папкой (удобно на телефоне);
- только `result.json` (без медиа).

Поддерживается экспорт одного чата и полный экспорт аккаунта (все чаты сразу).

## Повторный импорт

Чат узнаётся по его Telegram-ID. Если он уже есть в архиве, для него можно выбрать:
- **Дополнить**: новые сообщения добавляются, имеющиеся обновляются по ID сообщения. Дублей нет,
  старые сообщения, которых нет в новом экспорте, сохраняются;
- **Заменить**: старая версия удаляется целиком;
- **Создать новый чат**: отдельная копия;
- **Пропустить**.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты импорта
npm run build    # сборка в dist/
```

## Установка как приложение

Содержимое `dist/` нужно разместить на любом HTTPS-хостинге (GitHub Pages, Cloudflare Pages, Netlify).
После этого:
- **Windows**: открыть сайт в Edge или Chrome → значок «Установить приложение» в адресной строке;
- **Android**: Chrome → ⋮ → «Добавить на главный экран / Установить приложение»;
- **iPhone**: Safari → «Поделиться» → «На экран „Домой“».

После установки приложение работает без интернета.

## Ограничения

- Анимированные стикеры `.tgs` показываются как эмодзи (нужен Lottie-плеер).
- Голосовые в формате OGG могут не воспроизводиться в старых версиях Safari на iPhone.
- ZIP читается целиком в память. Для очень больших экспортов (несколько ГБ) на компьютере лучше выбирать папку.
